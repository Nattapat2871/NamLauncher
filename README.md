# NamLauncher 1.2.3 (Archived)

> **Repository archived / รีโปนี้เก็บถาวรแล้ว**

This personal repository preserves a cleaned, source-only snapshot of the
NamLauncher `1.2.3` desktop launcher. Active development has moved to the
official NamLauncher organization:

**Current repository:** <https://github.com/NamLauncher/NamLauncher>

รีโปส่วนตัวนี้เก็บ snapshot ที่ทำความสะอาดแล้วของตัว Launcher เวอร์ชัน
`1.2.3` เพื่อใช้อ้างอิงเท่านั้น การพัฒนาปัจจุบันย้ายไปที่
[NamLauncher/NamLauncher](https://github.com/NamLauncher/NamLauncher) แล้ว

## Archive boundary

This snapshot contains the Electron desktop launcher source, packaging files,
automated tests, and checksummed runtime artifacts required by launcher
`1.2.3`. It does not contain Minecraft companion source or build toolchains.

Website, API, Discord bot, authentication services, error-report processing,
deployment configuration, production data, credentials, and private keys are
not part of this repository. Those responsibilities are maintained separately
under private organization repositories.
