# Security Policy

## Supported versions

Security fixes are provided for the latest stable NamLauncher release. Old and
beta builds are not supported distribution channels.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. Do not open a public issue with exploit details, credentials,
private endpoints, user data, or production logs.

Include the affected version, operating system, impact, safe reproduction
steps, and any suggested mitigation. Remove access tokens, account identifiers,
machine paths, and personal data before attaching logs.
